# genzh releases

Signed release files for **genzh**, an unofficial open-source (GPL-3.0-or-later) Rust
engine that plays Command & Conquer Generals Zero Hour from your own installed copy of
the game.

This repository only hosts downloads for the genzh launcher and its updater. It contains
no game data: you need your own copy of the game to play.

## Status

No release has been published yet. When one is, the launcher will appear under
[Releases](../../releases), and the launcher keeps itself and the game programs up to
date from there. Every file is listed in a signed manifest and checked before use.
