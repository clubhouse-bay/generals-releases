# genzh releases

Downloads for **genzh**, a fan-made, open-source (GPL-3.0-or-later) engine for
Command & Conquer Generals: Zero Hour. It plays the game data of your own installed copy
of the game; it contains no game data itself. Source code:
[clubhouse-bay/genzh](https://github.com/clubhouse-bay/genzh).

## Download

**[Download genzh-launcher.exe](https://github.com/clubhouse-bay/generals-releases/releases/latest/download/genzh-launcher.exe)**
(Windows 10 or 11, 64-bit). The launcher finds your Zero Hour installation, installs
the game programs and keeps them up to date. Every update is listed in a manifest signed
with the project's release key and checked before it is installed.

## Code signing

Free code signing provided by [SignPath.io](https://signpath.io), certificate by
[SignPath Foundation](https://signpath.org). The launcher is built from the public source
repository by GitHub Actions; see the
[code signing policy](https://github.com/clubhouse-bay/genzh#code-signing-policy).
